# zKerbalismSpaceDust

**Version:** 1.0.0

Layer B (Native) satellite for [SpaceDust](https://github.com/post-kerbin-mining-corporation/SpaceDust) `ModuleSpaceDustHarvester` parts (including FFT atmosphere scoops when SpaceDust is installed).

## Features

- `SpaceDustHarvesterKerbalismUpdater` + Harmony resource blocking on native harvester `FixedUpdate`.
- Planner `PlannerController` entry.

## Dependencies

- Kerbalism, zKerbalismPluginHost, zKerbalismBridge, **zKerbalismNative**, SystemHeat, SpaceDust, Module Manager, HarmonyKSP.

## Installation

Copy `GameData/zKerbalismSpaceDust` into KSP `GameData`.
